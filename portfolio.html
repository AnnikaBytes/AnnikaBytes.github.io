Peak Trusted Peptides

B2B Wholesale Provider Portal & E-Commerce Store

I have been helping build this platform for a startup whose plan is to wholesale peptides securely to clinics and other medical professionals. The application features a secure online store where clinics can apply for access, view wholesale prices, and order products. I built the application form for clinics to sign up, created a secure admin dashboard to review and approve them, and integrated secure login using Google accounts.

The platform is a serverless application built with a Next.js frontend and an Express backend, and it is fully hosted on Amazon Web Services (AWS) using Lambda, DynamoDB, and S3. I also connected the store to Stripe to handle secure payments and process wholesale orders.

Current Status: Right now, the application is in a staging environment while we finalize some details. It is currently being hosted on an AWS CloudFront distribution, but it will be deployed to the actual production domain (PeakVitalityNow.com) later on!

CampReserveNow

Serverless Campsite Availability Checker & Reserver

Growing up, my dad and I used to go backpacking and camping all the time. There is one campsite in particular that my dad absolutely loves—the "Mestaa’ėhehe Mountain Fire Lookout" in Colorado—but it is extremely hard to book and always completely full. That frustration became the inspiration for CampReserveNow! It continuously monitors reservation availability on Recreation.gov and immediately alerts users via email or SMS as soon as a cancellation occurs or a new spot opens up.

The system is built with a responsive static web frontend backed by a robust, serverless AWS cloud architecture (Lambda, DynamoDB, EventBridge, SQS) to handle scheduled polling and instant notification routing at scale.

Current Status & Future Vision: CampReserveNow is currently in an invite-only early access mode. Visitors can explore the 3 different subscription tiers (Free, Warrior, and Pro) and join the waitlist for the plan they are most interested in. Once I finalize a few backend updates and fully connect the Stripe banking integration, I'll be opening the platform up to the public so everyone on the waitlist can start scoring their dream campsites!

Virtual World Simulation

Java Object-Oriented Programming Project

I built this sophisticated 2D virtual world simulation in Java during my freshman year at Cal Poly for my Project-Based Object-Oriented Programming class (CSC 203). The course focused on taking a basic procedural codebase and incrementally refactoring and scaling it into a robust, well-designed object-oriented system across a multi-part project.

Throughout the development process, I focused on core software engineering practices, including applying design principles (encapsulation, coupling, cohesion), utilizing interfaces and polymorphism to decouple components, translating UML class diagrams into functional code, and writing comprehensive unit tests.

The final simulation features A* pathfinding algorithms, dynamic entity behaviors, event scheduling, and animated rendering. To give it my own creative spin, I added a custom feature: when the user clicks the screen, a unicorn spawns and transforms lumberjacks into sword princesses who take over their jobs. After transforming two lumberjacks, the unicorn must be revived by the fairies!
